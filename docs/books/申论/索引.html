常见题型

归纳概括

  • 目标：找全、合并、分类、简洁表达。
  • 常见结构：主体 + 问题 / 做法 / 成效。

综合分析

  • 目标：解释含义、分析原因、指出影响、给出态度。
  • 常见结构：表态 / 释义 + 分析 + 对策或结论。

提出对策

  • 目标：针对问题给出可操作办法。
  • 常见结构：主体 + 动作 + 对象 + 目标。

贯彻执行

  • 目标：根据身份和格式写应用文。
  • 常见结构：标题 + 背景 + 主体内容 + 结尾。

申发论述

  • 目标：围绕总论点展开论证。
  • 常见结构：总论点 + 分论点 + 论据 + 对策 + 升华。
